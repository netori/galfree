## 4. 本轮交接给下一会话的**事实**(它们花了我不少时间才查明)

### Ren'Py SDK 的真实行为(实测,不是文档)

- `renpy.exe <project> <command>` 的第二个位置参数是**子命令**(lint/compile/…),
  **不是 label**;写未知串会 `exit 2` + usage。
- **`--warp` 的形式是 `<文件名>:<行号>`**(如 `script.rpy:15`),**不是 label**;
  给 label 会 `Exception: No : found in warp location`。我最后**没有采用**它 ——
  用"副本里覆写 `start`"更可靠(见 §5)。
- **`renpy --help` 会开窗并挂住**;跑它必须带超时/杀进程(我踩过一次 180s 超时)。
- `lint` 与 `compile` 对**启动期错误**都返回**退出码 0**:写错 config 变量名、布尔写成小写
  `true`,两者都抓不到。**唯一可靠的是真启动**(看 `traceback.txt` + 进程是否活着)。

### 方言子集与生成器的边界(本轮的架构决定)

- **`.rpy` 读取必须递归**(`src/service/rpy/files.ts` 是唯一出处):Ren'Py 与真 lint 都递归
  加载 `game/` 下任意深度。早先只读顶层,导致生成到 `game/scenes/` 的剧本"对板隐形、对真
  lint 可见" —— 两边判断会分叉。
- **一个 label 只归一个文件**:`game/script.rpy` 是手写/模板的家(生成器**不碰**),
  `game/scenes/<label>.rpy` 是生成的家。想生成还活在别处的 label → 拒绝并提示先**搬家**
  (`relocateScene`,人发起,段内容逐字不变)。
- **生成的场景若没人跳进去,就是 `orphan-scene`(error)**:这是完整性推导的正确行为。
  写测试夹具时要记得把生成的场接进主链,否则 `lint.ok` 会是 false(我在这上面栽了两次)。

### 宿主的坑

- 宿主目录选择接缝 `ctx.directoryPicker` 是**运行时 Loader 动态装配**的
  (`dsh-host-directory-picker-auto`),那一步失败是**静默**的 → 用户本次报"不能选择文件夹"
  很可能是这个。插件因此**自带 `directory-listing.ts` 作降级底座**,`browse` 恒可用。
  **这条修复用户还没验收过**(没重启)。
- 宿主按 `dsh plugin add link:` 装插件**不热挂载**,必须重启才加载新 `lib/`。

## 5. 本轮的关键实现决定(照抄,别重造)

- **T13"从某场试玩"**:在**临时副本**里把 `start` 覆写成 `jump <目标场>`,跑完即删 ——
  用户项目一个字节都不动。不在用户项目里塞临时 `.rpy`(`.rpy` 是唯一真相,副本不是)。
  信号**可红**:目标场不存在 → 启动即崩出 traceback。
- **T11 最小化 diff**:`行模型 → 只改被指向的那一行 → 拼回`,未编辑的行按**原文逐字**回写;
  表单把**注释与空行也列出来**(否则编辑一次就会吃掉它们)。`insertStatement` 支持**语义锚点**
  (给那一行的原文),别用绝对行号 —— 生成器头部占几行会让行号漂。
- **T10/T11 归属规则**:表单编辑只对生成目录里的场景开放;手写文件的场景**源文本模式仍可改**
  (那是人自己的文件,拒绝时要说清"先搬家")。
- **两个"被改过"分开判**(T9):`bibleFingerprint` 管派生物(戳失效),`outline.fingerprint`
  管原文(`outline-fingerprint-mismatch`)。别合成一个。
- **下游只读定稿版**(T9):`generationContext` 在没盖戳或已 stale 时抛 `bible-not-final`
  (409),不偷偷用草稿。

## 6. 会话内踩坑记忆(不在任何仓库文件里)

  写 GB 级脚本时优先用 `write` 工具而不是 `Set-Content`(后者会因编码损坏文件)。

- 一次性的探针/截图 harness 全在 `.scratch/`(gitignored),不污染仓库。
  真渲染面板的截图回路:`.scratch/harness/`(vite + playwright,`shots*.mjs`)——
