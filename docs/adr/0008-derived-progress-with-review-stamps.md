# 0008 — 进度为推导,认可为审读戳

- **状态**: Accepted(2026-07-27,grill R4-Q1)

## Context

"DSH 识别项目到哪一步"需要状态模型。纯推导(文件算出来,不说谎,但无法表达"人已认可")vs 纯声明(人勾里程碑,必与文件漂移)vs 混合。

## Decision

边界规则一句话:**客观可算的一律推导,算不出的才允许戳。**

- **推导进度**:场景缺对话、`.rpy` 引用图不存在、lint 未过、试玩未跑/未过——全部从项目文件+校验结果机械算出,可全量重算,两侧不得手改。
- **审读戳(review stamp)**:主观认可("这一幕定稿了")记入 `.studio/`。agent 不得擅设;**重生成自动清戳并要求复审**。戳粒度(方向:场景级、素材槽级)在 spec 定稿。

## Consequences

- 阶段推导引擎成为环节零核心模块(与校验回路并列):工作台阶段板与 DSH 端"识别项目状态"读同一引擎,无第二套真相。
- 试玩状态拆成两层:技术性通过(日志干净)可推导;主观"玩过了、行"是戳。两层都不手写。
