# 0010 — 自建生图通道,不依赖 dsh-imagegen

- **状态**: Accepted(2026-07-27,grill R5-Q2;取代 ADR-0007)

## Context

ADR-0007 曾选"agent 编排调 dsh-imagegen 工具"(省配置、借一致性判断的灵活性)。发起人 R5 推翻:**希望插件集成一套系统化的生图工具,不依赖外部生图插件。** 权衡变化:素材环节从"编排者"扩张为"完整子系统"(自建渠道配置、协议适配、任务与参考链管理);换来独立性(装机即用,不受第三方插件存废/接口变动牵制)。

## Decision

插件自带**图像子系统**:

- **渠道配置**:插件自有设置里管理(端点 + 密钥 + 模型目录),协议以 OpenAI 兼容为主、按上游个别适配;密钥明文存于本机设置(与 dsh-imagegen 同风险面,知情)。
- **任务模型**:"素材槽生成任务"为一级对象(目标文件、风格锚、参考图链、重试历史),产物一律经写网关落盘(ADR-0004)。
- 角色登记簿(ADR-0005, R4-Q5)继续作为一致性的锚:生成任务强制携带登记簿上下文,表情/姿势差分走参考链。
- **执行模型(R6-Q1)**:**Host 直连管道**——任务队列由 Host 持有,直连上游 API,不消耗 agent 回合,可批量、进度可追踪;agent 经同一队列的工具接口担任"美术指导"(调一致性策略、重roll、按对话意图建任务),不再为每次出图拉起子 agent 回合。
- 与 dsh-imagegen **无调用关系、不共享配置**;同机共存互不干扰。

## Consequences

- 素材环节工作量显著增加(0005 的环节四变厚);剧本/组装环节不受此变更牵连。
- 需要把"何时需要模型判断"结构化进任务对象(登记簿上下文+槽位模板+审读回路),队列接口对 agent 与工作台同时开放。
- 上游模型对参考图/图生图的协议支持参差,渠道适配要做降级报告(直说"该模型不支持参考链",不静默).
