# 0005 — 按环节横向建造,接缝契约先行

- **状态**: Accepted(2026-07-27,grill R3;环节顺序与环节零于 R4-Q3 定稿;素材通道于 R5 改判为 ADR-0010)
- **已批准修订(2026-09-12)**:环节 4 与环节 5 的边界**放宽** —— 素材环节不再只有立绘/背景/CG
  (加封面/主菜单背景/窗口图标),音频环节不再"无音乐生成、无 TTS"。三条生成线的接缝见
  **ADR-0012**(生成通道)与 **ADR-0013**(语音接线走对话 id + `config.auto_voice`)。
  原句保留在下面第 4/5 条(它是 v1 当时的事实),以这两份新 ADR 为准。

## Context

产品范围=全流程(ADR-0001…0004)。建造顺序上,主持访谈方两轮推荐"最薄垂直切片先行";发起人明确选择**按环节横向建造**。为对冲集成风险,设"环节零":先冻结并验证接缝契约,再逐环节横做。

## Decision

按环节横向建造,顺序:

1. **环节零(接缝契约)**:项目脚手架(模板新建,见下)+ 写网关骨架 + `.studio/` 元数据契约 + 钉版 SDK 与最小校验回路(lint/解析/能启动空游戏)。环节零交付=第一个可演示物。
2. **剧本环节**:对话/场景/分支的生成与工作台编辑,完成定义由环节零校验回路当场判定。
3. **组装试玩环节**:脚本+素材到可完整游玩的整线串联、试玩启动与结果回传。
4. **素材环节**:角色登记簿驱动的立绘/背景/CG 生成,经插件自建图像子系统(ADR-0010);**2026-09-12 起**再加封面 / 主菜单背景 / 窗口图标(仍走图像通道)。
5. **音频/发布环节**:BGM/SE 接线 + 本地打包(SDK `build_dists` 产物目录/zip;v1 无平台上传集成);**2026-09-12 起**再加**音乐生成**与**语音(TTS)生成** —— 接缝见 ADR-0012,语音接线口径见 ADR-0013。

**项目来源(R5-Q4)**:v1 只从插件模板新建项目;导入既有 Ren'Py 项目不进 v1(方言子集假设,ADR-0009)。

## Consequences(含已识别风险)

- **风险(发起人知情选择)**:第一个端到端可玩物晚于垂直切片路线;环节间接口若凭纸面设计,集成期可能集中爆炸。
- **对冲**:环节零把接缝变成已验证事实;每个环节的产物自交付日起即被校验回路与后续环节的 stub 消费者检验。spec 与 tickets 按环节组织。
- 每个环节 internal 的深度(如剧本环节的编辑体验)可以做得比垂直切片更高,这是该选择的收益面。
