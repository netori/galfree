# 0002 — 工作台是 DSH 插件内置的 Web 面板

- **状态**: Accepted(2026-07-27,grill 第 2 轮)

## Context

工作台(人用的全流程界面)与 DSH 端(agent + Host)必须双向同步。候选载体:

1. **插件内置 Web 面板**(选定):工作台作为本插件的 Client UI + Host 本地路由,人在 DSH 侧边栏/内置浏览器中使用,与 agent 同进程、同文件系统。
2. **独立应用**:自带壳或服务,通过本地 API 连 DSH——脱离 DSH 可用,但同步从"共同读写同一真相源"升级为"跨应用协议"。
3. 先 1 后拆 2:核心 Host 服务保持可被独立前端复用。

## Decision

工作台作为 DSH 插件内置的 Web 面板构建;项目核心逻辑放 Host 服务层,UI 层不承载独占逻辑(为将来可能拆出独立前端保留 seam)。

## Consequences

- 工作台的生命周期绑定 DSH:DSH 不开,工作台不可用(接受)。
- "DSH 识别项目状态"退化为进程内函数调用,同步复杂度大幅降低。
- 若日后要 (2),需新增跨进程协议——本 ADR 的 seam 约定使这一步是"加适配器"而非"重写"。
