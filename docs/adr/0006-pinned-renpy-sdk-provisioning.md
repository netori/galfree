# 0006 — 钉版 Ren'Py SDK 自动供给,手动兜底

- **状态**: Accepted(2026-07-27,grill 第 3 轮,Q2: A+B)

## Context

目标机器无 Ren'Py(事实探测)。流水线的校验环节(`.rpy` lint/解析/试玩启动)要求确定性的 SDK 版本;方言目标不能随用户机器漂移。

## Decision

- 插件 Host 在首次需要时自动下载**由插件版本钉住**的 Ren'Py SDK zip,解压至插件自有目录;`.rpy` 生成、校验、试玩统一使用该 SDK。
- 设置页允许指定/覆盖为既有 SDK 路径,并提供探测与引导(人自装的兜底)。
- 若覆盖版本与钉版不同,校验回路如实报告方言差异(警告,不阻止试玩)。

## Consequences

- 生成目标方言可复现:钉哪个版本,LLM 就按哪个版本的脚本规范写。
- 首次使用有百 MB 级下载成本;SDK 升级走插件发版(改钉版号)而非用户操作。
- 打包发布成品用 `renpy.sh`(或 Windows 对应 launcher)的 dist 构建,纳入"发布环节"。
